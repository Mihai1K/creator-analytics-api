# Смена центра: не блогер, а бриф рекламодателя

Раньше логика была `Блогер → метрики → аналитика → рекомендация`. Но рекламодатель приходит НЕ за
блогером — он приходит с задачей: «хочу 3000 установок», «продать курс», «лиды на новостройку».
Значит ядро продукта — **Campaign Intent**, а не Creator.
```
Бриф → AI → идеальный медиаплан → исполнение (Deal)
```

## Buyer Intelligence Engine (Этап 2 ⭐) — сделано (прототип)
AI превращает текстовый бриф в структуру Campaign Intent. Не «какая статистика у блогера», а
«что именно нужно рекламодателю». Демо (реальные результаты, `webui/intents.json`, экран `brief.html`):
- **Доставка еды, 300k** → KPI: CPI ≤200–220 ₽ + вторичный CPA первого заказа; площадки Telegram 90 /
  VK 87 / YouTube Shorts 66 / Дзен 58; **избегать Instagram** (Meta запрещена) и **TikTok** (нет загрузки с 2022);
  стратегия: 15–25 микро/мид, фикс+бонус за инсталлы, промокод+deeplink, ОРД.
- **Курс английского, 250k** → CPL ≤800 ₽ → ~300 заявок → 40–55 продаж; Telegram 90 / YouTube 74 / VK 70.
- **Новостройка СПб, 500k** → лиды; Telegram 88 / VK 84 / YouTube 70.
Схема Campaign Intent: goal · kpi{type,target,note} · budget · audience{age,gender,geo,interests} ·
categories · optimal_platforms[{platform,fit,why}] · avoid[{platform,why}] · strategy · summary.
→ дальше Recommendation Engine подбирает блогеров под ЭТОТ интент и объясняет «почему именно они».

## Knowledge Graph (Этап 3 ⭐⭐⭐) — сделано (seed)
«Бриллиант»: не таблицы, а СВЯЗИ. `knowledge_graph.py` строит граф из Marketing Intelligence:
узлы (блогеры, бренды, тематики, промокоды, площадки), рёбра (РЕКЛАМИРОВАЛ / ПРОМОКОД / ТЕМА / НА /
BRAND_SAFETY). Сейчас 59 узлов / 57 рёбер из реальных данных. Запросы работают:
- «Кто рекламировал Wildberries?» → demo_creator (промокоды DEMO10, DEMO461).
- «Бренды Воронина?» → SimpleEstate, ПАРУС, Accent, Альфа-Капитал.
Именно связи делают Recommendation умным: «Weekain часто рекламирует приложения, нет конкурента-бренда,
низкий CPV» вместо «вот похожие». Пополняется автоматически из каждого поста (MI) и — в будущем —
из каждой кампании (Learning: ребро blogger-[CPA 214₽/ROMI 312%]->brand).

## Порядок разработки
1. Intelligence Engine ✅ (заморожен). 2. **Buyer Intelligence Engine** ✅ (прототип). 3. **Knowledge Graph** ✅
(seed, растёт). 4. Marketing Intelligence — извлекает знания в граф (✅ на Telegram). 5. Learning Engine —
когда накопятся тысячи реальных кампаний (data-dependent). Затем Prediction/Simulation.

## Горизонт 3–5 лет: ОС рынка influence-маркетинга
Не сервис аналитики блогеров, а инфраструктура принятия решений: платформа знает кто продаёт лучше,
кому подходит блогер, сколько реально стоит интеграция, когда запускать, какие бренды конфликтуют,
какие комбинации дают результат, какие переговорные стратегии работают. Моат = накопленная база знаний
(блогеры + бренды + категории + история + результаты + связи + модели на своих данных) — некопируемо.
Тест каждой фичи: «повышает качество решения медиабайера — или просто ещё одна цифра?»
