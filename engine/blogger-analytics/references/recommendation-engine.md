# Recommendation Engine — design (коммерческое ядро BloggerMarket)

Intelligence Engine (v1.0, заморожен) отвечает на вопрос «какой этот блогер?».
Recommendation Engine отвечает на вопрос, за который **платят**: «кого купить под МОЮ задачу и бюджет,
и какой будет результат?». Это слой, который превращает аналитику в кампанию — и в выручку.

## Почему рекламодатель заплатит через платформу, а не пойдёт напрямую
Прямой контакт с блогером даёт одну карточку. Платформа даёт то, что в одиночку не собрать:
1. **Подбор** — из тысяч авторов автоматически 12 лучших под бюджет/гео/цель (ниже).
2. **Прогноз** — охват, переходы, CPV/CPM, вероятность KPI ещё до оплаты.
3. **Deal Layer (моат)** — контакты блогера раскрываются **только после покупки**. До этого — аналитика и подбор, но не «уйти напрямую».
4. **Операционка** — договор, оплата, маркировка ОРД, отчёт закрытия в одном месте (CRM-слой).
Ценность и защита бизнеса — в связке подбор+прогноз+сделка, а не в самом факте «показать блогера».

## Вход: AdvertiserBrief
```json
{ "budget": 500000, "goal": "installs|leads|awareness|sales",
  "product": "шеринг пауэрбанков", "category": ["tech","city-lifestyle"],
  "geo_cities": ["Спб","Мск","Казань"], "audience": {"age":"18-35","gender":"any"},
  "kpi": {"type":"CPI","target": 60}, "platforms": ["TikTok","Telegram","YouTube","VK"],
  "stop_factors": ["алкоголь","политика"], "max_bloggers": 12 }
```
Через **AI Buyer** бриф пишется естественным языком → LLM извлекает эту структуру (см. ниже).

## Конвейер
```
Кандидаты (Intelligence Engine: score, quality, cpv, платформа, размер)
   │  1. HARD-фильтры (must-pass, иначе выкинуть с причиной)
   ▼     • гео содержит целевые города   • комплаенс РКН ок/фиксимо
        • платформа разрешена            • нет стоп-факторов   • Quality ≥ пола
   │  2. CONTEXTUAL FIT (0–100) — под ЭТОТ бриф, НЕ общий Score:
   ▼     fit = w1·audience_fit(гео%+возраст/пол) + w2·cost_efficiency(CPV vs target)
              + w3·topic_overlap(product↔категория) + w4·data_confidence(Quality)
              + w5·engine_signal(Score/Risk).  Отсутствие гео/категории → штраф + флаг «нужен медиакит».
   │  3. PORTFOLIO под бюджет (не просто топ-N):
   ▼     жадно/knapsack макс. прогноз-KPI в рамках budget
        + дедуп пересечения аудитории (не платить дважды за тех же зрителей)
        + диверсификация (лимит на платформу/сегмент)
   │  4. FORECAST:
   ▼     охват (Σ), уникальный охват, переходы/установки (через CR), CPV/CPM, вероятность KPI, бюджет
   │  5. EXPLANATIONS: по каждому «почему выбран» + сводка кампании
   ▼
RankedCampaign
```

## Выход: RankedCampaign
```json
{ "bloggers": [{ "name","platform","cost","expected_reach","cpv_est","fit","why":[...] }],
  "media_plan": {"budget_used", "count", "by_platform"},
  "forecast": {"reach","unique_reach","installs_est","blended_cpv","cpm","kpi_probability"},
  "confidence": "high|med|low", "data_gaps": ["гео по городам","категория","прошлые интеграции"],
  "rationale": "текст" }
```

## AI Buyer (следующий большой UX-слой)
Рекламодатель: «Хочу продать курс английского, бюджет 250к».
→ LLM извлекает Brief → Recommendation Engine → LLM пишет ответ:
«Изучили 14 000 блогеров, лучше всего подходят 18. Ожидаемый CPM… CPV… Вероятность KPI…».
Магия — не в анализе блогера, а в анализе **задачи рекламодателя**.

## Данные, которых пока нет (честно) и как деградировать
Для точного подбора нужны per-blogger: **гео аудитории по городам**, возраст/пол, тематика/категории,
история интеграций/конверсий. Публичные логаут-данные их не дают → движок:
- всё равно ранжирует по доступному (CPV, размер, Score, Quality, платформа),
- помечает `confidence` и `data_gaps` (что запросить: медиакит за 30 дней, платформенный API),
- НЕ выдумывает гео/категорию (принцип «недоступно ≠ estimated»).
Точность растёт по мере обогащения — это же топливо для платного медиакит-аудита и Snapshots.

## Прототип
`scripts/recommend.py` — рабочая реализация конвейера (hard-фильтры → fit → portfolio под бюджет →
forecast → why) поверх замороженного Intelligence Engine. Демонстрируется на реальном пуле блогеров.

## Место в коммерческом роадмапе
```
Intelligence Engine ✅ (v1.0 FROZEN)
   → Recommendation Engine   ← ЭТОТ модуль (ядро продукта)
   → Campaign Builder        (бриф → медиаплан + прогноз, self-serve)
   → Deal Engine             (подборка → купить → раскрыть контакты)  ← МОАТ
   → CRM                     (статус → диалог → договор → оплата → ОРД → закрытие)
   → Payment · ORD · Analytics
```
Правило: Intelligence Engine больше не расширяем полями/формулами — только баги. Вся новая ценность строится ЗДЕСЬ.
